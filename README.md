# Native State Tools

This repository is the homepage for Native State Tools, a suite of private, local-first web tools. It is a static site made of plain HTML and CSS. There is no build step.

The live site is nativestatetools.com.

State CV is the first tool. The homepage links to it. The footer links to the Native State Tools organization on GitHub.

## Preview locally

From this folder, start a static file server and open the address it prints.

```
npx serve .
```

If Python is available:

```
python -m http.server
```
