# Agent notes

Rules for changes to this homepage:

- Plain HTML and CSS only. No frameworks and no build step.
- Do not add JavaScript unless it is truly needed. If you add it, use a classic script. Never use `innerHTML`.
- Keep the strict Content-Security-Policy meta tag. No inline style attributes and no inline scripts.
- No analytics, trackers, CDNs, external fonts, or other third-party requests.
- Keep changes small. Use one branch per change.
- Never push or merge.
